# Book Recommendation
The collection of books in Lead city University library has greatly increased over the years. While there are many valuable resources in the library in form of books, the willingness and amount of time for students to search through and find one mostly preferred book is a challenge.
Based on computer science books in Lead City University library, this paper chooses the item-based collaborative filtering algorithm for recommendation. The system being proposed uses collaborative filtering that first construct the user-item interaction matrix, then construct vector matrix using cosine similarity measure from user-item interaction matrix and then find the similarity between the books using Pearson coefficient and it recommends the top n books similar to the book given by the user as input to the algorithm. This paper presents a system that strives to supply users with an effortless and quick method to find the right book.
